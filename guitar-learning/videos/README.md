# Guitar Learning Videos

ใส่วิดีโอเดโมจริงไว้ในโฟลเดอร์นี้เพื่อให้ `index.html` เล่นได้ทันที

ไฟล์เริ่มต้นที่หน้าเว็บอ้างอิง:

- `a-minor-p1-slow-demo.mp4`
- `a-minor-p1-slow-demo.vtt`
- `a-minor-p1-narration.wav`

แนวทางทำวิดีโอ:

1. ถ่ายฟรีตบอร์ด 45-60 วินาที เล่น A Minor Position 1 ช้า ๆ ขึ้นและลง
2. ใส่เสียง voice guide ใน DAW หรือ CapCut ให้ตรงกับ cue ในไฟล์ `.vtt`
3. เก็บไฟล์เสียงต้นฉบับเป็น WAV ได้ เช่น `a-minor-p1-narration.wav`
4. Export เป็น MP4 H.264 + audio ขนาด 1080p หรือ 720p
5. วางไฟล์ MP4 ในโฟลเดอร์นี้ หรือใช้ Cloud URL ในช่อง Video Demo Player
