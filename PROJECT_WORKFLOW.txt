เป้าหมาย
ใช้ไฟล์นี้เป็น workflow ประจำวันสำหรับแก้เว็บ, เช็กระบบ, commit, และ push โปรเจกต์ myserver

ตำแหน่งโปรเจกต์
/Users/2pfamily/Library/Mobile Documents/com~apple~CloudDocs/myserver

โครงสร้างหลัก
index.html
  หน้า Home รวมลิงก์ไป app ต่างๆ

coffee-shop/
  POS ร้านกาแฟ static

library/
  Library Lab static + เชื่อม Google Apps Script

guitar-learning/
  Guitar Learning 12 weeks / 84 days training player

running-app/
  Running Log และ dashboard

space-game/
  Space Explorer game

workflow แก้เว็บ static
1. เปิดไฟล์ app ที่ต้องแก้ เช่น coffee-shop/index.html หรือ running-app/index.html
2. แก้เฉพาะส่วนที่เกี่ยวข้องกับงาน
3. ถ้าเพิ่มลิงก์กลับ Home:
   - หน้าในโฟลเดอร์ชั้นเดียวกับ app ใช้ ../index.html
4. เช็กหน้าตาใน browser
5. เช็ก diff:
   git diff -- ไฟล์ที่แก้
6. เช็ก whitespace:
   git diff --check
7. commit และ push ตาม workflow Git ด้านล่าง

workflow Git ประจำวัน
1. กลับ root โปรเจกต์:
   cd "/Users/2pfamily/Library/Mobile Documents/com~apple~CloudDocs/myserver"
2. เช็กสถานะ:
   git status --short --branch
3. ดูว่าแก้อะไร:
   git diff
4. stage เฉพาะไฟล์ที่ต้องการ:
   git add path/to/file
   หรือถ้าตั้งใจเอาทุกไฟล์:
   git add .
5. commit:
   git commit -m "สรุปงานสั้นๆ"
6. เช็กว่า commit สำเร็จ:
   git status --short --branch
   git log -1 --oneline --decorate
7. ถ้าขึ้น [ahead 1] ให้ push:
   git push
8. เช็กอีกครั้ง:
   git status --short --branch

วิธีอ่านสถานะ Git
## main...origin/main
  clean และ sync แล้ว

## main...origin/main [ahead 1]
  commit แล้ว แต่ยังไม่ได้ push

Changes to be committed
  staged แล้ว แต่ยังไม่ได้ commit

Changes not staged for commit
  แก้ไฟล์แล้ว แต่ยังไม่ได้ stage

COMMIT_EDITMSG เปิดอยู่
  commit อาจยังไม่จบ ให้พิมพ์ข้อความ commit บรรทัดบนสุด แล้ว save/close

ก่อน commit ทุกครั้ง
1. git status --short --branch
2. git diff --check
3. ตรวจว่าไม่มีไฟล์ลับ:
   credentials.json
   .env
   node_modules/
   public/uploads/
   .DS_Store
   nohup.out
6. รัน security checks:
   node scripts/build-public-site.mjs
   node scripts/verify-public-site.mjs _site
   node scripts/check-tracked-secrets.mjs

หลังแก้หน้า Home
1. เช็กการ์ดใน index.html
2. เช็ก href ไป app ต่างๆ
3. เช็กว่า app ที่เพิ่มมีปุ่มกลับ Home
4. เปิดทดสอบจาก browser อย่างน้อยหนึ่งครั้ง

หลังแก้ปุ่มกลับ Home
1. app ชั้นเดียว เช่น space-game/index.html ใช้ ../index.html
2. dashboard ภายใน running-app ใช้ ../index.html เพื่อกลับ Home หลัก
3. ปุ่มไม่ควรทับปุ่มสำคัญเดิม

workflow กู้ระบบ VS Code Tunnel
1. เข้า iMac ด้วย AnyDesk
2. ล็อกอินบัญชี 2pfamily ให้ถึง Desktop
3. ปิด VS Code บน iMac ให้สนิท
4. เปิด Terminal
5. รัน:
   code tunnel service uninstall
   code tunnel service install
6. ถ้าเจอ GitHub device code ให้เข้า:
   https://github.com/login/device
7. ใส่ code และ authorize
8. รอข้อความ Tunnel service successfully started

กฎสำคัญ
ห้ามใช้ git reset --hard ถ้าไม่มั่นใจ
ห้าม commit ไฟล์ลับ
ห้ามลบงานคนอื่นใน repo โดยไม่ตั้งใจ
แก้เฉพาะไฟล์ที่เกี่ยวกับงานนั้น
ถ้าจะลบ dependency หรือ node_modules ให้เช็ก .gitignore และสถานะ Git ก่อนเสมอ
